# 班薪记

面向倒班员工的个人工资记录网页。React 19 + TypeScript + Vite；没有业务后端、注册或上传工资数据的接口。浏览器 localStorage 保存账本，手机和桌面响应式布局。

## 启动与测试

需要 Node.js 22.12+ 或 Node.js 24 LTS。在本项目目录执行：

```powershell
npm ci
npm run dev
```

打开终端显示的 Local 地址（通常为 `http://localhost:5173`）。也可右键使用 PowerShell 运行 `start.ps1`。电脑和手机在同一网络时，使用终端显示的 Network 地址。需要电脑允许该开发服务通过本机防火墙；网页代码本身不更改防火墙。

```powershell
npm test              # 独立计算函数的单元测试
npm run build         # 严格 TypeScript 检查与生产构建
npm run preview       # 本地预览 dist
npx playwright install chromium
npm run test:e2e      # 浏览器交互及手机布局测试
```

可选浏览器配置：PowerShell 中设置 `$env:PLAYWRIGHT_CHANNEL='msedge'` 使用已安装且允许自动化的 Edge，或设置 `$env:PLAYWRIGHT_EXECUTABLE_PATH` 指向兼容的测试版 Chromium。默认使用 Playwright Chromium。本次验收使用独立 Chromium 测试浏览器，没有更改系统浏览器策略。

## 第一次使用

1. 「工资规则」核实工时制度、加班基数、部分周期折算分母、福利标准与发放方式，然后保存。
2. 「考勤日历」点击日期或新增班次。时间未核实的排班保留草稿，草稿不计薪。选择符合实际的加班类型，不能仅看周末。
3. 「工资总览 → 本周期参数」选择完整或部分周期，填写实际计薪天数、绩效、津贴资格与扣款；有实际依据再打开确认开关。
4. 「工资条核对」逐项录入工资条与实际到账，项目合计不自动当作银行到账。工资条确认不自动追加收入，以免重复计薪。
5. 「保存工资快照」锁定当前规则、考勤和计算明细。「数据与备份」查看快照、修改记录、导出 CSV 或备份与恢复 JSON。

工资周期月份指结算截止月。选择 **2026-09** 可直接查看历史工资条七项 **¥715.42**；已预存原始历史快照。选择 **2026-10** 为 2026-09-26 至 2026-10-25。

## 计算约定与数据保护

- Decimal.js 使用 40 位有效数字。金额以十进制字符串存储；小时单价和中间金额不先取整。同类、同确认状态的加班先合并，工资项目最后按人民币分四舍五入或截取，汇总各项目分金额。因此历史七项合计精确为 ¥715.42。
- 月基本工资只生成一笔。工作日按班次开始日期共享一次标准工时额度，同日分多段记录不会重复获得 8 小时正常额度，跨午夜也不重置。休息日已补休不自动按双倍计费。未确定的加班类型不先猜测工资，计薪工时会作为待确认事项提示。
- 周期按班次开始日期归属，特殊日期按跨午夜实际时段拆分。吃饭按上班后偏移分钟定位，默认 240 分钟；短休息默认不扣。重叠休息合并，避免重复扣除。实际吃饭发生时间未知时，这个位置只是一项可修改默认值。
- 手动计薪工时优先，不再减去休息。跨日期默认按原计薪时段比例分配，界面明确提示；可逐段指定工时与类型。逐段小时必须全部填写、和总工时相等且不超出相应时段。
- 未录入日期不推定出勤、缺勤或休息。完整周期基本工资是一项明确标示的预测假设；缺勤扣款须输入依据和实际金额，不从缺勤天数自动推算。
- 现金、饭卡等非现金、发放方式未知分别汇总。月餐补与逐班餐补未确认互不重复时，月餐补不会同时进入现金预测。
- 绩效基数空白时不自动生成绩效；¥68.25 只用于历史周期。高温与礼金须按周期启用。个税仅录入实际扣款，不在累计预扣资料不足时输出估算。
- 保存规则会增加规则版本。依赖旧规则的确认金额转为预计，需重新核验；已录入的实际金额及历史快照保留。周期编辑和考勤编辑也会保留确认依据对应的规则版本。
- 所有保存、修改、删除与恢复均保留前后值及备注。不可变快照记录保存时的结果；当前预测会随规则变化，历史工资条实际数据不被计算结果覆盖。
- 重复考勤 ID、重叠出勤时段、非法日期与数值、无效 JSON 都会被拒绝。读取损坏本地数据时不覆盖原文，可导出原始内容；存储写入失败会提示，界面不会假装保存成功。
- CSV 使用 UTF-8 BOM，兼容中文 Excel，并转义逗号、引号、换行与公式注入字符。JSON 恢复前导出原账本；恢复采用整体替换，不能作为合并导入。CSV 用于查看，不能恢复完整账本。
- 本地数据按浏览器与网址隔离，不自动跨设备同步。换网址、设备或清理浏览器前请导出 JSON。HTTP 局域网访问与 localhost 也有独立的本地账本。

## 初始数据与日期依据

仅初始化需求中提供的记录：9/24 入职办理、9/25 确认的 11.5 小时节假日工时、10/4 清洁 8 小时、10/8 已知夜班时段、10/12 休息待确认。9/25 和 10/4 的钟点未知，界面备注明确为参考时段，计薪小时使用已知值。10/5 只知道切换夜班，实际时段未确认，保留为不计薪草稿。未推断整月出勤。

预置日历**仅覆盖 2026 年中秋、国庆相关日期**，可新增、替换或删除。未设置的日期不因为周末或连续假期而自动按休息日加班计算。其他年份或节日需要补齐后核验。

- 2026 年中秋 9/25，国庆法定日 10/1–10/3；连续放假日另存。
- 2026 年 9/20、10/10 是官方调休工作日；个人是否实际上班仍由考勤决定。
- [国务院办公厅关于2026年部分节假日安排的通知](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)
- [全国年节及纪念日放假办法（2024年修订，国务院公报）](https://www.gov.cn/gongbao/2024/issue_11726/material/gwygb202433.pdf)

## 仍需本人确认

| 事项 | 当前处理 |
| --- | --- |
| 工时制度及综合计算工时审批 | 默认为尚不确定，显示估算 |
| 每周期应计薪、实际计薪天数及日折算分母 | 可逐期设置，默认分母 23 为历史推得 |
| 缺勤扣款依据 | 不自动扣薪，实际金额手动录入 |
| 月餐补现金或饭卡、是否与白班餐补重复 | 默认未知，分开发放汇总 |
| 夜班津贴资格与实际金额 | 预计 ¥25/班，逐班修改和确认 |
| 高温适用月份、资格及实际金额 | 默认不启用，可按周期开关 |
| 正式员工绩效标准与折算办法 | 标准留空，只录入本期实际绩效 |
| 国庆礼金、正式员工礼金 | 仅按需求给出默认福利标准，需按期核验 |
| 社保、公积金基数费率、个税实际扣款 | 不猜测基数或费率，缺项明确提示 |
| 参考钟点、吃饭时间与加班归类 | 逐班修改，支持跨午夜分段修正 |

## 项目结构

```text
src/
  domain/
    model.ts       数据模型、输入和备份校验
    dates.ts       无时区漂移的民用日期与工资周期
    engine.ts      独立高精度工资计算、分段与工资条核对
    seed.ts        已知初始数据和历史工资条
    storage.ts     localStorage、JSON 与 CSV
    engine.test.ts 计算与数据单元测试
  components/
    Overview.tsx   工资总览与逐笔公式
    Attendance.tsx 考勤日历、班次编辑、排班草稿
    Rules.tsx      工资规则与独立日期类型日历
    CycleEditor.tsx 周期计薪、福利与扣款
    Reconcile.tsx  工资条逐项核对和到账记录
    ui.tsx         通用表单与弹窗
  App.tsx          导航、持久化、审计、快照和导入导出
  styles.css       手机和桌面布局
e2e/app.spec.ts    浏览器交互验收
```

这是浏览器网页小程序，可直接在手机浏览器使用；没有包含微信原生小程序发布包、云同步或自动累计个税估算。
